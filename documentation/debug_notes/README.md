# Debug notes

One file per investigation, named `YYYY-MM-DD_short_topic.md`.

These are records of problems that took real work to diagnose — what the
symptom looked like, what the measurement actually showed, and, just as
importantly, **which explanations turned out to be wrong**. The wrong turns
are kept on purpose: they are what stops the next person spending a day
re-testing a hypothesis that was already ruled out.

A note is worth writing when the answer was not obvious from the code, when
the first explanation was wrong, or when the conclusion needs to survive
until someone acts on it weeks later.
