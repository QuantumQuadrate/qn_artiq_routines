# Standalone stack (independent-Kasli experiments)

Explorer entry points for the original standalone two-Kasli system. This stack
freezes once the DRTIO master-satellite gateware migration is validated; the
master-satellite stack at the repository top level is the successor. Shared
infrastructure stays outside this folder (`utilities/`, `subroutines/`,
`fitting/`, configs), as do the already-foldered standalone consumers
(`tests/`, `MOT_experiments/`). See `plan_codex_detail.md` /
`plan_codex_consise.md` at the repository root.
